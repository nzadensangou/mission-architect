# Script de démonstration — 4 minutes

Objectif : montrer en une démonstration continue qu'un choix de conception se traduit
immédiatement en conséquence de mission.

## 0:00 — Accueil (15 s)

- Ouvrir l'application : logo, nom, menu.
- Survoler les quatre entrées : « reprendre », « nouvelle mission », « options », « quitter ».
- Cliquer sur **Nouvelle mission**.

## 0:15 — Choix de mission et briefing (25 s)

- Sélectionner **Observer la Terre** (missions suivantes visibles mais verrouillées).
- Lire l'objectif : 600 observations en 30 jours, budget 80 M$.
- Cliquer sur **Continuer**.

## 0:40 — Lanceur (20 s)

- Choisir **Lanceur Moyen** : 400 kg, 32 M$, 94 % de fiabilité.
- Mentionner le compromis : le lanceur lourd doublerait presque le coût.

## 1:00 — Construction (75 s)

Ajouter dans l'ordre : structure, deux panneaux solaires, batterie, caméra standard,
antenne standard, orientation.

- Montrer la masse (165 kg), le budget restant (8 M$) et l'énergie (+19,2 kWh/j).
- **Moment clé** : retirer un panneau solaire → le message « énergie insuffisante » apparaît
  et le bouton de lancement se désactive. Le remettre.
- Lancer la mission.

## 2:15 — Simulation (90 s)

- Accélérer en **Rapide**, laisser défiler quelques jours.
- Au premier événement, lire les options et choisir **Économiser** pour traverser l'ombre.
- Désactiver brièvement l'antenne pour montrer l'accumulation de données en attente, puis la
  réactiver.
- Activer **Observation renforcée** et pointer l'augmentation d'observations au coût énergétique.
- Montrer le journal et les jauges qui réagissent.

## 3:45 — Résultat (15 s)

- Laisser la mission se terminer (ou utiliser la fin de journée 30).
- Afficher le score, le rang et le rapport ; déplier les graphiques batterie / observations.
- Conclure : « chaque point de score correspond à une décision d'ingénierie ».

## Points à préparer

- Navigateur en mode sombre, zoom 100 %, fenêtre 1440×900.
- `npm run build && npm run preview` pour une démo fluide.
- Vérifier le volume audio avant la démonstration (options → audio).
